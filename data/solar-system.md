# 太阳系天体：位置与轨道数据

> 这份文档是**时间栏 + 太阳系天体**功能的数据依据。所有数字都来自公开星表/官方机构，
> 没有一个是编造或用 AI 生成的。可复现命令在最后一节。

## 1. 结论先行：用两套办法

| 天体 | 数量 | 位置怎么算 | 精度 |
| --- | --- | --- | --- |
| 太阳、月球、水星…海王星、冥王星 | 11 | **astronomy-engine**（VSOP87 + JPL 长年理论），在浏览器里实时计算 | 最高 |
| 谷神星、灶神星、智神星、阋神星、鸟神星、妊神星 | 6 | d3-celestial 带的**开普勒轨道根数** + 自己解方程 | 中等（见 §4） |
| 著名彗星 | 23 | **MPC（国际小行星中心）** 彗星根数 + 自己解方程 | 中等偏上 |

之所以要两套：`astronomy-engine` 只覆盖 8 大行星 + 冥王星 + 月球，**不含矮行星和彗星**；
而它算得比通用开普勒推进准得多，所以行星交给它，其余自己做。

## 4. 精度验证（这一步很重要）

我用自己的开普勒推进算出行星位置，和 `astronomy-engine` 的 VSOP87 结果逐点对比
（`tools/verify-planets.mjs`，5 个日期 × 8 个天体）：

| 天体 | 最大偏差 | 占其轨道半径 |
| --- | --- | --- |
| 水星 / 金星 | 0.00001 – 0.00007 AU（1500–11000 km） | < 0.01 % |
| 火星 | 0.00035 AU（5.2 万 km） | 0.02 % |
| 木星 | 0.0076 AU（110 万 km） | 0.15 % |
| 土星 | **0.0300 AU（450 万 km）** | **1.9 %**（最差，1900 年） |
| 天王星 / 海王星 / 冥王星 | 0.004 – 0.009 AU | 0.02 % |

这符合 JPL 对该方法的说明：**1800–2050 年之间精度最好，外行星和时间离 J2000 越远误差越大**。
1.9% 的距离误差在做可视化时完全可以接受（土星在屏幕上偏一点点而已）。

## 5. 已知局限（要写进 plan.md 的假设）

1. **矮行星/小行星用的是"瞬时根数"**（历元 2015-06-27），只有 `M` 和平均运动 `n` 做线性外推，
   没有摄动项。谷神星这类受木星摄动明显的天体，推算到几十年外会有可观误差。
   解决方向：换 JPL SBDB 或 MPC 的完整根数表。
2. **彗星根数的历元是 2026-10-15**，所以"现在"附近最准；离这个时间越远误差越大，
   木星族彗星尤其明显（它们的轨道会被木星改变）。
3. **双曲线/近抛物线彗星**（e ≥ 1，如 ʻOumuamua、鲍里索夫）不能用椭圆开普勒方程，
   需要用通用变量（Stumpff 函数）或巴克方程求解 —— 实现时要单独处理。
4. 智神星（Pallas）暂时没有可靠来源的中文名，界面上会显示英文。
5. 时间只影响太阳系天体，**不影响恒星**：最近的恒星在 4.2 光年外，而地球绕太阳一圈才
   1 AU（0.0000158 光年），恒星在视觉上完全不动。

## 6. 怎么重新生成

```bash
# 1. 取 MPC 彗星根数（完整版，2208 颗）
node tools/download.js https://www.minorplanetcenter.net/iau/Ephemerides/Comets/Soft00AllCmt.txt data/raw/CometElsAll.txt

# 2. 解析彗星表 -> data/raw/comets-all-parsed.json
python tools/parse_comets.py

# 3. 生成网页用的数据 -> web/data/solar-system.json
python tools/build_solar_system.py

# 4. 精度交叉验证（需要 astronomy-engine，见下）
node tools/verify-planets.mjs
```

`astronomy-engine` 的浏览器 ESM 构建放在 `web/vendor/astronomy/astronomy.js`，离线可用。

## 7. 位置计算要用到的公式（备忘）

赤道坐标 J2000 下的轨道根数 → 日心黄道坐标：

```
ω = W − N                          # 近日点幅角
M = L − W  （归一化到 ±180°）       # 平近点角
解 E − e·sinE = M                  # 开普勒方程（牛顿迭代）
x' = a(cosE − e),  y' = a√(1−e²)·sinE
x = (cosω·cosN − sinω·sinN·cosi)·x' + (−sinω·cosN − cosω·sinN·cosi)·y'
y = (cosω·sinN + sinω·cosN·cosi)·x' + (−sinω·sinN + cosω·cosN·cosi)·y'
z = (sinω·sini)·x' + (cosω·sini)·y'
```

再用黄赤交角 ε = 23.4392911° 转到赤道坐标，才能和 HYG 恒星数据放在同一个坐标系里：

```
y_eq = y·cosε − z·sinε
z_eq = y·sinε + z·cosε
```

矮行星/彗星给的是 `M`（或 `Tp` 过近日点时刻），行星给的是 `L`（平黄经），注意区分。
彗星没有 `M`，要从 `Tp` 反推：`M = n·(t − Tp)`，其中 `n = 0.9856076686 / a^1.5` 度/天。
